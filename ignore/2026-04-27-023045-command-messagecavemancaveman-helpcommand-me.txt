● Good approach. Systemd user timer — runs every N minutes, checks /status,
  kills Steam if locked and running. Catches steam.real direct bypass too.

  Three files needed:

  1. Watchdog script (~/.local/bin/gym-gate-watchdog.sh):
  #!/usr/bin/env bash
  if ! /home/aryan/.local/bin/gym_gate_check.py >/dev/null 2>&1; then
      if pgrep -x "steam" >/dev/null || pgrep -x "steam.real" >/dev/null; then
          pkill -x "steam"
          pkill -x "steam.real"
          notify-send "Gym Gate" "Steam killed — gym check-in required."
  --urgency=critical 2>/dev/null || true
      fi
  fi

  2. Service unit (~/.config/systemd/user/gym-gate-watchdog.service):
  [Unit]
  Description=Gym Gate Steam watchdog

  [Service]
  Type=oneshot
  ExecStart=/home/aryan/.local/bin/gym-gate-watchdog.sh

  3. Timer unit (~/.config/systemd/user/gym-gate-watchdog.timer):
  [Unit]
  Description=Gym Gate Steam watchdog timer

  [Install]
  WantedBy=timers.target

  [Timer]
  OnBootSec=2min
  OnUnitActiveSec=5min

  Enable:
  chmod +x ~/.local/bin/gym-gate-watchdog.sh
  systemctl --user daemon-reload
  systemctl --user enable --now gym-gate-watchdog.timer

  Verify:
  systemctl --user status gym-gate-watchdog.timer
  systemctl --user list-timers

  User service = same session as Steam, so pkill hits it. notify-send works on
  KDE Plasma Wayland with user services. Fires every 5 min — short enough to be
  annoying, not so short it hammers the Fly.io server.
